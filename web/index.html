                          How to read the timeline
                          • Each agent is a lane; its faint band runs from its first event to its last.
                          • A mark is an event at the moment its line was written. A tool call long enough to see is a bar as long as it took.
                          • Red marks failed: an error, a failing test, a commit that did not happen.
                          • Drag across the time axis to zoom to a stretch; click a phase to zoom to it; Fit shows the whole run again.
                          • The Activity row is always the whole run; while zoomed it shows where you are, and a click moves there.
                          • Replay steps through what was recorded; nothing is run again. Two agents' events in the same millisecond are outlined, since their order is not known.
                          • A lane's label hides or shows it; the kind chips above hide or show a kind.
